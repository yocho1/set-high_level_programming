# 0x10. Python - Network #0

## Description
This project introduces the basics of networking with Bash and ` sending HTTP requests and inspecting response data such as body size and headers.curl` 

## Requirements
- Ubuntu 14.04 LTS
- All scripts must be executable
- `curl` is required
- Scripts are tested against a local web server running on port 5000

## Files

| File | Description |
| --- | --- |
| `0-body_size.sh` | Bash script that takes a URL and displays the size (in bytes) of the response body |
