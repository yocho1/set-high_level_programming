The ``5-text_indentation`` module
====================================

Using text_indentation
-------------------------

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Basic usage with periods, question marks and colons:

    >>> text_indentation("Hello. How are you? Fine: thanks")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks

Text with no terminating punctuation at the end:

    >>> text_indentation("Just one sentence")
    Just one sentence

Empty string prints nothing:

    >>> text_indentation("")

text must be a string:

    >>> text_indentation(12)
