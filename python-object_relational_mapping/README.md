# 0x0F. Python - Object-relational mapping

## Description
This project introduces object-relational mapping (ORM) in Python, connecting to and interacting with a MySQL database using the `MySQLdb` module.

## Requirements
- Python 3.4
- MySQL 5.7
- MySQLdb module (`pip3 install mysqlclient`)
- All scripts should be PEP 8 compliant

## Files

| File | Description |
| --- | --- |
| `0-select_states.py` | Lists all states from the `hbtn_0e_0_usa` database, sorted by `id` |
| `0-select_states.sql` | SQL script to create the `hbtn_0e_0_usa` database and `states` table with sample data |
